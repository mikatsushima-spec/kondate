# きょうのごはん / kondate

小学生が使う「きゅうしょく」と、家族が選ぶ「ゆうごはん」。スマートフォン向けの日本語PWAです。

## できること

- 日本時間の今日の給食、前後の日、カレンダーで選んだ日の給食を表示。
- アプリ内でPDFを選択し、日ごとの料理名・牛乳マーク・休み・行事を読み取り。
- 対応PDFは選ぶだけで自動保存し、子どもの画面へ表示。必要なときだけ設定から編集。
- 別の形式やスキャンPDFは、原本を見ながら手入力。
- 64点の料理イラスト。未対応の料理は「おさら」を表示し、保護者が絵や写真を指定。
- 11種類の夕食（ネットで確認した時短レシピ3品を含む）と「別のメニュー」「前のメニュー」「今日はこれにする」。
- 献立・3手順・画像生成プロンプト・4人分の買い物リストが同じレシピに連動。
- カレーとシチューは合わせて月〜日曜の週1回まで。候補を眺めるだけでは回数を使いません。
- 苦手な食材の除外、お気に入り、今週の夕食記録、買い物チェック。
- PDF・追加写真も含む端末内保存、JSONバックアップと復元、給食の前回保存への復帰。
- ホーム画面に追加。公開先で準備が完了すると、登録した内容と画像をオフライン表示。

## はじめて使う

1. スマートフォンでアプリを開く。
2. 「献立PDFを入れる」からPDFを選ぶだけ。対応するPDFは年月を推定して自動登録します。
3. 確認・編集・確定は不要。必要なときだけ「おうちのひと」から修正できます。
4. 土日も学校行事で給食がある場合があるため、自動確定しません。必要なら「未登録の土日を給食なし」にします。
5. 以後は起動時に今日の給食を表示。「おうちのひと」を3秒長押しすると編集・バックアップを開けます。

3秒長押しは誤操作防止です。認証・アクセス制限ではありません。公開先の閲覧権限とGitHubの公開範囲は別に管理します。

## PDF対応範囲

初版の自動読み取りは、提供された9月献立表と同じ列構成の文字PDFに対応しています。PDF.jsで文字座標と牛乳欄の画像位置を読み取り、自動登録します。

- 上限10MB、5ページ。パスワード付き・破損PDFは拒否。
- 年がない場合は作成年を基準に、前後2年を曜日と照合して推定。推定できない年月・曜日の不一致や重複は保存しません。
- 文字がないスキャンや違う表形式は手入力。OCRやAIの推測による自動入力は行いません。
- 記載がない日は「未登録」。登録月以外に古い献立を転用しません。
- イラスト・写真は料理のイメージ。学校の実物や原材料を保証するものではありません。
- 元資料の栄養価は学年換算が必要なため、この版では栄養価を表示しません。

## 夕食について

「別のメニュー」は候補を一巡しても自動で次の周回へ進み、何回でも使えます。決定済みの夕食も変更できます。ネットで調べた麻婆豆腐・チキンソテー・焼きすき風を、4人分と簡単な副菜にアレンジして収録。出典リンクを各カードに表示します。毎回のリアルタイムWeb検索ではありません。さらに探すための公式サイトリンクもあります。

主菜は、しゃぶしゃぶ、蒸し鶏、牛こま焼き、ポークステーキ、肉じゃが、トマト煮、カレー・シチュー。副菜は切るだけ・生野菜・酢漬け・レンジ加熱に限定しています。調理時間は目安で、炊いたごはんまたは冷凍ごはんを使用します。肉の火通りを確認し、必要な場合は追加加熱してください。

ホットクックの機種が未設定のため、初版は通常の鍋・フライパン・電子レンジの手順です。操作番号を推測して表示しません。提案は端末内のレシピカタログを使用し、外部AI APIや継続課金を必要としません。

## データの保存

献立PDF、日別の献立、追加写真、夕食の履歴はブラウザのIndexedDBだけに保存されます。サーバーへの送信や分析トラッキングはありません。ブラウザや機種が変わると別の保存領域になります。機種変更・ブラウザのデータ削除前にバックアップしてください。プライベートブラウズは使わないでください。

このリポジトリには個人の献立PDFや登録データは含めません。`public/food`の画像はこのアプリ用に生成した汎用素材です。

## 開発

Node.js 22.13以上、package.json記載のpnpmを使用します。

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm build
```

標準スターターのVinext / React / TypeScript / Shadcnを使用。PDF読み取りはpdfjs-dist。保存はIndexedDB、オフライン表示はService Workerです。ビルド後に`scripts/prepare-offline.mjs`が、実際のハッシュ付きJS/CSSをキャッシュ対象に追加します。

Sites環境では付属の実行プロファイルとビルド・公開手順を使用します。`.openai/hosting.json`は公開先の識別子のみで、秘密情報は入れません。GitHubはソースコードの保管先で、このままGitHub Pagesに配置する構成ではありません。

## ファイル

- `components/meal-app.tsx`: 今日・日付・給食・親向け画面の入り口
- `components/lunch-import.tsx`: PDF選択・原本・確認・編集
- `components/dinner-view.tsx`: 夕食提案と3つの出力
- `components/parent-panel.tsx`: 記録・設定・バックアップ
- `lib/pdf-layout.ts`: 対応する給食表の座標解析
- `lib/dinners.ts`: レシピと週1回制限
- `lib/storage.ts`: 保存とバックアップ検証
- `docs/requirements.md`: 実装要件と制約
- `docs/verification.md`: 実際に行った動作確認

## 素材とライセンス

料理画像はこのアプリのために画像生成で作成しています。表示用にWebP圧縮。外部サイトの料理写真は使用していません。PDF.jsはApache-2.0、その他の依存ライブラリは各パッケージのライセンスに従います。詳しくは`docs/assets.md`を参照してください。
